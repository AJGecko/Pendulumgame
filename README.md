> Did you know that "Pendel" is the German word for pendulum?

## Play the Game

* **Live Play:** [Play on microStudio](https://microstudio.io/AJGecko/pendelgame/)
* **Project Page:** [microStudio Project Overview](https://microstudio.io/i/AJGecko/pendelgame/)

## Controls
| Action | Keyboard | Touch / Mouse |
| :--- | :--- | :--- |
| **Collect Point / Catch** | `Space` | Tap / Click anywhere on screen |
| **Pause / Resume** | `P` | Tap on-screen Pause button |

## About the Game
You have a constantly swinging pendulum. The goal is to collect as many yellow (or blue) points as possible by pressing the screen or the spacebar at the moment the pendulum is over a point. Blue points also provide an additional 10 seconds of time.

## Built With

* **Engine:** [microStudio](https://microstudio.dev/)
* **Language:** microScript 2.0

## How to Run / Open the Project

1. Go to the **Releases** tab on GitHub and download the latest `.zip` archive of the project.
2. Open [microStudio](https://microstudio.dev/) and go to the create tab.
3. Import the downloaded `.zip` file.
4. Hit **Run** to play and experiment with the code!

> The project data/files is/are located in the game folder. Zipping and importing it would also work.
