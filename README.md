# Pendel Game by AJGecko

A web game with a pendel.

You have a constantly swinging pendulum. The goal is to collect as many yellow (or blue) points as possible by pressing the screen or the spacebar at the moment the pendulum is over a point. Blue points also provide an additional 10 seconds of time.

You can pause the game with p or using the pause button on the screen.

Play: https://microstudio.io/AJGecko/pendelgame/

Project page on microStudio: https://microstudio.io/i/AJGecko/pendelgame/

To open the project itself, use the zip (releases).

Build with microStudio and microScript 2.0
